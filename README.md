# Spectrum Paint — Website Redesign

A modern, editorial-style redesign for Spectrum Paint Ltd.

## Direction
- Premium architectural/materials-brand aesthetic
- Large typography and photography-led layouts
- Interactive colour studio
- CSS motion and scroll reveals
- Responsive mobile layout
- Quote request flow via WhatsApp
- No Spectrum Paint logo asset included in this repository

## Run locally

This is a static site. Open `index.html` directly, or serve the folder with any static server.

## Notes
The photography currently uses remote Unsplash images as visual placeholders. Replace these with approved Spectrum Paint photography and product renders before production launch.

Do not commit credentials, `.env` files, private API keys, or proprietary brand assets without approval.
